## Краткое описание

Создаем код для оценки надежности паролей.

После ввода пароля выставляется рейтинг от 0 до 10. Чем выше рейтинг, тем надежнее пароль.

Пароль проверяется на следующие условия:
1. Наличие цифр 
2. Наличие заглавных букв
3. Наличие строчных букв
4. Наличие спецсимволов (! ; @ / и т.д.)
5. Длину (более 12 символов)

За соответсвие каждому условию пароль получает 2 балла.
